PORTFOLIO — READY TO UPLOAD

Files:
- index.html — the original portfolio HTML, renamed to the standard web entry point.

No visual/design changes were made to the HTML.

GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html.
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder / (root).
5. Save and wait for the public URL.

Netlify:
1. Open Netlify and choose Add new project / Deploy manually.
2. Upload this folder (or extract the ZIP first).
3. Netlify will publish index.html as the site homepage.
